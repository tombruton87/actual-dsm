When syncing goes quiet

A device that's signed out, or can't reach the Synology, carries on working alone — and its changes aren't backed up here. DSM can tell you when no budget has synced for a while.

Budget file size

The biggest budget a device may upload. Twenty megabytes covers years of transactions; raise it if a big budget won't sync.

Actual's server has one password, shared by everyone who uses your budgets. Each budget can also have its own encryption password, set in Actual — the server never sees that one.

Open Actual on a phone

Scan it, sign in with the server password, then Add to Home Screen (Safari: Share → Add to Home Screen; Chrome: ⋮ → Install app). Actual then opens like an app and works offline.

The server password

Lost it? Make a new one — shown once. Devices that are signed in stay signed in unless you sign them out too.
